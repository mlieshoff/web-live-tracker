# Web Live Tracker

Web Live Tracker ist eine Browser-Erweiterung für Chrome und Firefox auf dem Computer. Sie speichert verfügbare Anfragen und Antworten aus dem ausgewählten Tab auf deiner Festplatte. Die Dateien sind nach deiner Kennung, dem Datum und der Webadresse sortiert.

| Browser | Installation und Benutzung |
| --- | --- |
| Chrome | [Deutsche Anleitung für Chrome](chrome/README_DE.md) |
| Firefox | [Deutsche Anleitung für Firefox](firefox/README_DE.md) |

Im jeweiligen Browser-Ordner findest du die passende ZIP-Datei und beide Sprachfassungen der Anleitung.
